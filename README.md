# Ai Productivity Pricing Calculator and Quote Builder Tool

A comprehensive pricing calculator and quote builder tool designed specifically for the ai productivity industry.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
